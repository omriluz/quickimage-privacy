ForceLens — Salesforce Record & SOQL Inspector Privacy Policy

Last updated: 2026-09-29

Data used

ForceLens reads the URL of the active tab to confirm it is an HTTPS Salesforce or Force domain and to detect a Lightning record object and ID. It reads the sid session cookie associated with that active org and tab cookie store. It sends the user's read-only SOQL and authenticated GET requests directly to that same validated Salesforce org. Returned record and query data are displayed temporarily in the popup.

The active session cookie remains inside the extension background service worker. It is not returned to the popup, written to extension storage, logged, included in exports, or sent to a caller-selected host. Redirects are disabled for credential-bearing requests.

Storage, sharing, and export

ForceLens has no analytics, telemetry, advertising, remote scripts, or third-party service. It does not persist queries or Salesforce results. Data leaves the popup only when the user explicitly downloads all loaded query results as a local CSV file. Salesforce itself receives the API requests as part of the requested workflow.

Permissions

  • activeTab: identifies the active page after the user opens ForceLens.
  • cookies: reads the Salesforce session cookie required for direct API authentication.
  • Salesforce and Force host permissions: read the matching cookie and make REST requests only on supported Salesforce hosts.

Retention and deletion

The extension retains no Salesforce data. Closing the popup discards its in-memory results. Exported CSV files are controlled and deleted by the user through their device.

The result table uses 50-row pages to keep the popup responsive. “Export loaded CSV” includes every fetched row across those pages, within the documented query limits.

Local and functional data use

ForceLens handles active org URL, session cookie and record/query data in memory, potentially including personal information; optional local CSV exports. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
