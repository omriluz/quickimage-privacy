BlazeFree Local Text Expander Privacy Policy

Last updated: 2026-09-29

BlazeFree stores snippet shortcuts and content, enabled-site records, and the latest pre-import backup in chrome.storage.local in the user's Chrome profile. It does not include telemetry, advertising, accounts, billing, or developer-operated network processing.

BlazeFree does not store general text typed into web pages. On a website the user has explicitly enabled, its local content script receives browser input events and inspects only enough text immediately before the active caret to find a saved shortcut. It does not use a page-wide keydown logger. It does not expand in password inputs, recognized card/payment fields, or elements marked by the page as sensitive/private. It does not submit forms.

Site access is optional. The extension requests access to the current HTTP(S) site only after the user presses Enable. Enabled sites are shown in the popup, persisted locally, and removed from Chrome permissions when disabled. Chrome host-permission patterns cover all ports on that scheme and hostname. BlazeFree separately gates expansion to the exact enabled origin, including its port. The extension does not inject into cross-origin frames in v1.

Export happens only when the user requests a JSON download. Import reads the file the user selects locally, validates it, and makes no change until the user chooses merge or replace. An import backup remains in local extension storage until used or superseded.

Chrome may include local extension data in browser/profile backup mechanisms controlled by Chrome or the operating system. BlazeFree does not claim that local storage is encrypted or synchronized.

Local and functional data use

BlazeFree handles user-authored snippet text, saved site origins and transient caret-adjacent text/input events; snippets may contain sensitive user-authored content. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
