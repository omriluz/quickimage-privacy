VetTrack: VA Claim Snapshot Privacy Policy

Effective date: 2026-09-29

VetTrack reads visible text from the active VA.gov claim status or claim details page only after the user opens the extension and clicks Capture current page. It may process and store a visible claim title, claim type, status, page title, redacted page URL, and capture time.

The latest capture is stored in chrome.storage.local in the user’s Chrome profile. Long numeric or UUID-like claim identifiers in the URL path are replaced, and URL query strings and fragments are not stored. Data remains until the user deletes one claim, deletes the complete capture, or uninstalls the extension. Chrome profile sync is not used.

VetTrack does not include telemetry, advertising, billing, remote code, or a developer backend. It does not intentionally collect or transmit claim snapshots, medical records, account credentials, or browsing history to the publisher or third parties. The user’s normal interaction with VA.gov remains governed by VA.gov’s own privacy and security practices.

Permissions:

  • activeTab provides temporary access after the user invokes VetTrack.
  • scripting runs the packaged reader for the requested capture.
  • storage saves the latest capture locally.

VetTrack is independent and is not affiliated with, endorsed by, or operated by the U.S. Department of Veterans Affairs.

Local and functional data use

VetTrack handles claim title/type/status, page title, redacted page URL and capture time; claim details can contain health and personal information. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
