ConfidentialMode: Screen Blur Privacy Policy

Last updated: 2026-09-29

ConfidentialMode has one purpose: visually blur user-selected elements on webpages.

Data handled

When you choose to save rules for a site, ConfidentialMode stores:

  • the site's origin, such as https://example.com; and
  • CSS selectors generated from DOM structure, a stable element ID, or a stable data-testid, data-test, or data-qa value.

The extension reads page structure as needed to identify and visually mask the element you select. It does not store selected text, images, form values, screenshots, browsing history, or page contents. One-time selections are represented by CSS classes and temporary filter/selection styles in that document; original style values are kept in page memory for restoration and disappear when the document closes or reloads.

Storage and transmission

Saved rules are stored in chrome.storage.local on the user's device. ConfidentialMode has no analytics, advertising, account system, remote server, or data sale. It does not transmit webpage content, saved selectors, browsing activity, or usage data to the publisher or a third party.

Permissions

  • activeTab: temporary access to the page where the user invokes the extension.
  • scripting: injects the local blur controller into that page.
  • storage: saves optional site rules locally.
  • Optional HTTP(S) site access: requested only when the user enables saving for the current site; it lets saved masks reapply on later visits to that exact origin.

Users can remove a site's saved rules and optional access with Forget rules & access, even when that site has no saved rules. Removing the extension also removes its local storage through Chrome.

Security and limitations

Blur is a visual mask, not encryption or redaction. Original webpage data remains available to the webpage and in its DOM. The extension package contains all runtime code and does not execute remote code.

Chrome host permissions cover the selected scheme and hostname across all ports. Saved selectors remain tied to the exact page origin, including its port. Forget rules & access removes the site's saved selectors and the hostname permission; this can also stop automatic masks on other ports of that hostname until access is granted again.

Local and functional data use

ConfidentialMode handles page structure, saved site origins and CSS selectors; temporary styles in page memory. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
