ApplyFlow: Job Application Autofill & Tracker Privacy Policy

Last updated: 2026-09-29

ApplyFlow stores the applicant profile and tracked job records the user chooses to save in chrome.storage.local inside the current Chrome profile. Profile fields can include name, email, phone, city, country, and profile/portfolio links. Tracker records can include job title, company, page URL, status, and local timestamps, capped at 500 records. Stored URLs omit credentials, fragments and query parameters other than explicit job identifiers (gh_jid, jobId, jid). Content scripts cannot directly read profile/tracker storage; the chosen profile is sent to the page tool only when you invoke review.

When the user selects Review current page, Chrome's activeTab permission gives ApplyFlow temporary access to that page. The extension reads visible form labels and current values to prepare a local preview, and reads a likely job title/company to prefill the optional tracker fields. It changes only selected, empty standard controls after the user confirms in the page panel. It does not submit forms, attach files, read a resume, or fill sensitive demographic, legal, eligibility, sponsorship, criminal-history, birth/age, or compensation answers.

ApplyFlow makes no network requests and contains no analytics, advertising, remote code, account system, or cloud database. It does not sell user data or transmit it to the extension developer. Values you choose to fill become available to the destination webpage; that site may process or transmit them before you submit. Data remains in extension-local browser storage until the user edits/removes records or uninstalls the extension. Chrome extension storage is local persistence, not encrypted vault storage; anyone with access to the Chrome profile may be able to access it.

Permissions:

  • storage: save the applicant profile and application tracker locally.
  • activeTab: temporarily inspect and update the page only after the user invokes ApplyFlow.
  • scripting: load the review/fill code into that user-invoked page.

Local and functional data use

ApplyFlow handles name, email, phone, location, profile links and local job/application URLs and statuses. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
