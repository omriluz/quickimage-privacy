CanvasMaster: What-If Grades & Dark Theme Privacy Policy

CanvasMaster processes Canvas course grading information locally in the active browser tab after the user invokes the extension and clicks Load course grades.

Data accessed

For the numeric course ID in the active Canvas Grades-page URL, CanvasMaster sends same-origin, read-only GET requests for the course and its assignment groups, assignments, and the signed-in user's available submission scores. Canvas session cookies are handled by the browser and are sent only to the active Canvas origin. CanvasMaster does not read passwords or authentication tokens.

Storage and sharing

  • Course names, assignments, scores, and hypothetical scores are not written to extension storage.
  • Hypothetical scores exist only in the current page's memory and disappear when the page reloads or navigates.
  • The dark-theme preference is stored in chrome.storage.local.
  • There is no telemetry, advertising, remote backend, or third-party data transfer.

Permissions

  • activeTab: temporary access to the page where the user invokes CanvasMaster.
  • scripting: injects the planner and theme into that active page.
  • storage: saves only the dark-theme preference.

CanvasMaster does not submit assignments, edit course data, or change official grades. It has no persistent host permission.

Local and functional data use

CanvasMaster handles course names, assignments and scores in page memory; dark-theme preference locally; browser-managed Canvas session authentication for same-origin read-only requests. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
