QuickImage Privacy Policy

Last updated: October 2, 2026

This policy applies to QuickImage - WebP, PNG & JPG Converter.

Data handling

QuickImage does not include analytics, advertising, accounts, or a publisher server. When the user chooses a conversion, Chrome fetches the selected image from the image's existing HTTP or HTTPS host. The bytes are decoded and re-encoded inside a temporary Chrome offscreen document, then passed to Chrome's download manager. QuickImage does not transmit the image to a separate conversion service.

The data handled for this feature includes website content (the selected image), web-resource information (the selected image URL and origin), and user activity (the local conversion count and last operation's status and timestamp). Handling this data locally is still disclosed as data use. QuickImage does not monitor unrelated pages or maintain a record of visited pages.

The image request goes to its existing host and may follow that host's redirects. That host receives the requested resource URL and ordinary network connection information. QuickImage's request omits cookies and other browser credentials. No image, URL, or conversion activity is sent to a QuickImage publisher server or a separate conversion service.

QuickImage's use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the image-conversion feature and its local settings and status. QuickImage does not sell user data, transfer it for unrelated purposes, use it for advertising, or use it to determine creditworthiness or for lending. The publisher does not receive or read the locally processed images or local activity records.

The extension stores these items locally in chrome.storage.local:

  • The user's JPG/WebP quality setting.
  • A completed-conversion count.
  • The last operation's status, generic message, and timestamp.

It does not store the selected image URL, filename, image bytes, page URL, or browsing history. Granted host access is managed by Chrome and remains until the user removes it in the QuickImage popup or Chrome's extension settings. The popup lists every saved HTTP(S) origin before offering one control that removes the entire displayed list.

Permissions

  • contextMenus: adds PNG, JPG, and WebP choices when the user right-clicks an image.
  • downloads: starts the converted-image download with a sanitized filename.
  • offscreen: opens a hidden, bundled document while Chrome decodes and encodes the image.
  • storage: keeps the quality setting, conversion count, and last generic result.
  • Optional http://*/* and https://*/* host access: allows the extension to fetch the selected image. Access is requested for that image's exact origin at conversion time, rather than granted to every site at installation.

No content scripts are injected. No remote code or runtime dependency is loaded.

Retention and deletion

Popup settings and status remain in local extension storage until the extension is removed or its storage is cleared. The popup's Remove all site access button revokes every listed HTTP(S) image-host permission previously granted to QuickImage.
