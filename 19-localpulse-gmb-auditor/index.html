LocalPulse: Maps Business Audit Privacy Policy

Last updated: September 29, 2026

Data LocalPulse handles

When the user clicks Capture current Maps business, LocalPulse reads the current Google Maps place URL and supported visible business details: business name, primary category, rating, review count, link, and coordinates when present in the place URL’s data parameters. The current URL is also used to establish a place identity for deduplication.

LocalPulse does not read these fields continuously. It does not read unrelated tabs, Google account credentials, cookies, browsing history, profile-management data, or hidden business fields.

Use, storage, and sharing

The captured fields are used only to display and maintain the user’s saved audit list and to generate a CSV at the user’s request. Records are stored with chrome.storage.local on the user’s device. Chrome clears that extension storage when the extension is removed. LocalPulse does not operate a server, transmit audit records to the developer or third parties, sell data, use analytics, or show ads.

The user can remove one record or clear all saved records from the popup. A CSV export is downloaded to a location controlled by the user and is no longer managed by the extension.

Permissions

  • activeTab grants temporary access to the current tab following the user’s invocation.
  • scripting runs bundled capture code in that temporarily authorized tab.
  • storage maintains the local audit list.

LocalPulse requests no persistent website host permission.

Data retention and security

Records remain until the user removes them, clears the list, clears extension storage, or uninstalls LocalPulse. Chrome extension local storage is not represented as encrypted storage. Users should avoid capturing information they consider sensitive and should protect exported CSV files according to their own needs.

These fields must be completed and the hosted policy must match this packaged behavior before publication. Stored Maps links omit credentials, fragments, and incidental query parameters. Place identity tokens retain their original case. Only visible supported elements are read; hidden stale page elements are excluded.

Local and functional data use

LocalPulse handles business names, categories, ratings, review counts, links, coordinates and Maps URLs; business details may identify an individual proprietor. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
