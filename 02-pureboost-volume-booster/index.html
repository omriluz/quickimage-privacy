PureBoost: Tab Volume Booster Privacy Policy

Last updated: September 29, 2026

PureBoost processes audio from the browser tab that the user explicitly selects. Processing happens locally in Chrome memory through the Web Audio API so the adjusted audio can play through the current default output device.

Data handled

  • Selected-tab audio: captured transiently in memory while boosting is active. PureBoost does not record, save, upload, transmit, sell, or share it.
  • Per-tab preferences: volume percentage and bass-boost state are stored in chrome.storage.session, keyed by Chrome's numeric tab identifier. They are removed when that tab closes or Chrome exits.
  • Runtime status: active/error state is stored temporarily in chrome.storage.session so the popup reports confirmed capture state. It is not sent anywhere.
  • Current tab URL: the popup reads the selected tab URL only to reject browser-internal or unsupported pages. The URL is not stored or transmitted.

PureBoost has no analytics, advertising, account system, remote service, or network request in its runtime code.

Permissions

  • activeTab: temporarily reads the selected tab URL after toolbar activation to identify supported pages; no page content is read.
  • tabCapture: obtains audio from the tab chosen through the toolbar action.
  • offscreen: hosts the local Web Audio graph after the popup closes.
  • storage: stores the per-tab controls and temporary capture status described above.

PureBoost requests no host permissions and does not read page content.

Retention and deletion

Audio exists only in the live media pipeline and is released when boosting stops, the stream ends, or the tab closes. Per-tab preferences are removed when the tab closes or Chrome exits. Removing the extension deletes its Chrome-managed local and session storage.

This repository document is release copy; it is not yet a hosted privacy policy.

Local and functional data use

PureBoost handles selected-tab audio and transient current-tab URL; local volume/bass preferences and session state. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
