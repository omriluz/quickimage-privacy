ClosetPace: Own Closet Review Checklist Privacy Policy

Last updated: October 2, 2026

ClosetPace operates locally in Chrome. It has no developer server, analytics, advertising, billing, telemetry, or remote code.

Data processed

After the user invokes the extension, ClosetPace reads the active page URL, the signed-in profile link exposed on the page, and currently rendered listing links and titles. It uses those values in memory to verify an own-closet page and build a manual review checklist.

Review marks exist only in the injected panel for the current page. ClosetPace does not store them in Chrome storage or send them anywhere. It does not press Share, select a destination, submit marketplace actions, or claim that a listing was shared.

Credentials and challenges

ClosetPace does not request, read, or store a Poshmark password, session cookie, payment information, or message content. It blocks scanning when it detects a CAPTCHA or verification challenge and does not solve, submit, or bypass it.

Permissions

  • activeTab provides temporary access to the tab selected through the toolbar.
  • scripting injects the local review checklist into that tab after the user's click.

There is no storage permission, persistent host permission, or always-on content script.

Sharing and sale of data

ClosetPace does not sell, transmit, or disclose user data to the publisher or third parties.

Local and functional data use

ClosetPace handles current profile/closet identity, visible listing titles/links and current page URL; checklist state in page memory. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
