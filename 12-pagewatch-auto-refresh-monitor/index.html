PageWatch: Auto Refresh Monitor Privacy Policy

Data behavior

PageWatch processes the visible text of a tab only after the user explicitly starts monitoring that tab. Matching happens locally in Chrome. Page text, patterns, URLs, monitor state, and notification state are not sent to the developer or any third party.

The extension has no analytics, telemetry, advertising, account system, remote API, or payment integration.

Local storage

PageWatch stores a random browser-session identifier and recent result state in chrome.storage.session. The identifier is generated locally and is used only to prevent persisted tab IDs from being reused after a full browser restart. When the session identifier is absent, persisted monitors are discarded.

Stopping a monitor removes its active local record and alarm. A stop-on-match result may remain in session storage until the browser session ends, the tab closes, the tab crosses to another origin, or the user starts or stops that tab's monitor again.

Permissions

  • activeTab provides temporary access after the user opens PageWatch on the selected tab.
  • alarms schedules later reload cycles.
  • notifications displays a local match-state change alert.
  • scripting reads visible page text after a monitored reload completes.
  • storage holds local monitor and session state.
  • tabs identifies, reloads, observes, and cleans up the selected tab.

PageWatch requests no host permissions. It does not inspect unrelated tabs, run automatically on visited sites, bypass site controls, submit forms, or click page elements.

Retention and deletion

Users can remove active monitor state by selecting Stop monitoring, closing the monitored tab, navigating it to another origin, disabling the extension, or uninstalling it. Uninstalling removes extension-managed Chrome storage under Chrome's normal extension data lifecycle.

This file describes version 1.0.0 source behavior. The hosted privacy policy must match the reviewed release package.

Local and functional data use

PageWatch handles monitored page text, pattern, origin/URL and local monitor/check/alert state. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
