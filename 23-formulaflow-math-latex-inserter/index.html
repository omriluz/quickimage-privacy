FormulaFlow: Offline LaTeX Equations Privacy Policy

Last updated: September 29, 2026

FormulaFlow processes LaTeX equations locally inside the extension. It does not transmit equations, history, clipboard contents, usage events, or identifiers to the publisher or to a third party. It contains no analytics, advertising, telemetry, account system, remote fonts, or external rendering API.

Data stored on the device

After a successful copy or download, FormulaFlow saves the equation's LaTeX source, a random local item ID, and a creation timestamp in chrome.storage.local. It keeps up to 25 recent equations. Users can delete individual entries from the popup. Chrome controls the underlying extension storage and its removal when the extension is uninstalled.

Clipboard and downloads

When the user clicks Copy LaTeX, FormulaFlow writes the current equation source to the clipboard. When the user clicks Copy PNG, it renders the current equation into a local canvas and asks Chrome to write an image/png item. The extension does not read existing clipboard contents.

When the user clicks Download SVG or Download PNG, FormulaFlow creates the file locally in the popup and starts a normal browser download. No equation data is uploaded.

Permissions

  • storage stores recent equations locally.
  • clipboardWrite performs the user-requested copy action.

FormulaFlow requests no website access or host permissions.

Local and functional data use

FormulaFlow handles user-entered equation text and up to 25 local recent equations with identifiers and timestamps. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
