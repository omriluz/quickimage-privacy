GridGrab — Table & Card Exporter Privacy Policy

Last updated: September 29, 2026

GridGrab processes page content only after the user clicks Scan current page. It reads the currently selected tab using Chrome's temporary activeTab access and extracts visible text, links, image alternative text, and table structure from the chosen page area. The preview and export data remain in extension memory for the current side-panel session.

GridGrab does not transmit page content, browsing history, exports, or usage data to the publisher or any third party. It has no analytics, advertising, account system, remote API, telemetry, or persistent data storage. CSV files are created locally and handed to Chrome's normal download flow. TSV is written to the system clipboard only when the user clicks Copy TSV.

Permissions

  • activeTab: temporarily access the current page after the user invokes GridGrab.
  • scripting: inject the local scanner into that user-selected tab.
  • sidePanel: display the extraction controls and preview alongside the page.

The extension requests no host permissions and cannot scan protected Chrome pages where injection is disallowed. Users remain responsible for complying with website terms, access controls, privacy obligations, and applicable law when exporting page data.

Local and functional data use

GridGrab handles selected page text, links, image alternative text and table structure; preview/export data held in session memory. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
