DialPop: Click-to-Call Preview Privacy Policy

Data handled

When the user clicks Scan current page, DialPop reads visible text from that one active page to locate likely phone numbers. Page text and scan results remain in the browser and are not sent to a DialPop server.

DialPop stores these settings in chrome.storage.local: selected provider, explicit default country, custom HTTPS template, and dynamic-page preference. When the user clicks Open dialer, DialPop also stores up to 50 local dial-intent entries containing the normalized number, provider type, generated route, and timestamp. Users can delete the entire intent history from the popup. The URL of each explicitly scanned tab is kept temporarily in chrome.storage.session to authorize its page controls; it is removed on tab closure or when Chrome clears session storage. Content scripts cannot read local settings or intent-history storage directly.

External disclosure

Route preview is local. If the user separately clicks Open dialer, Chrome passes the generated route to the system tel: handler or opens the chosen HTTPS provider. That provider may receive the destination number and process data under its own terms. DialPop does not test routes, place calls itself, listen to audio, record calls, verify connection, or receive provider account data.

Permissions

  • activeTab: temporary access to the page on which the user invokes DialPop.
  • scripting: injects the packaged scanner only after the user clicks Scan current page.
  • storage: saves local settings and the deletable dial-intent log.

DialPop has no persistent host permissions, analytics, advertising, billing, remote code, or developer-operated backend.

Local and functional data use

DialPop handles phone numbers, scanned page/resource information, local provider/template settings and recent dial-intent timestamps. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
