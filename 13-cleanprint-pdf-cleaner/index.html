CleanPrint — Reader & Print Preview Privacy Policy

Last updated: 2026-09-29

Data handled

The extracted snapshot is held temporarily in chrome.storage.session so a separate extension page can open it. The preview removes that session entry after loading. Chrome clears session storage when the extension is disabled, reloaded, updated, or the browser restarts. CleanPrint does not keep article history.

Network behavior

CleanPrint does not send article text, titles, URLs, or usage data to a developer-operated server. It has no analytics or telemetry.

Remote images are disabled in the preview by default. If the user explicitly chooses Show images, the browser requests those image URLs from the original site or its image hosts. Those hosts can receive normal request information such as the user's IP address, browser headers, and referrer behavior determined by Chrome. CleanPrint does not control those sites or promise that image requests remain local.

Links in the preview open only after the user activates them and can navigate to external sites.

Permissions

  • activeTab: temporarily reads the page the user chose after invoking the extension.
  • scripting: runs the bundled visible-content extractor in that chosen tab.
  • storage: passes the bounded snapshot through in-memory session storage to the isolated preview.

CleanPrint requests no persistent host permissions.

Sharing, sale, and retention

The extension developer does not receive, sell, or share page content or usage data. The extension contains no advertising or tracking SDK. A user can close the preview at any time; the source page remains unchanged.

These fields must be completed and the deployed policy verified before submission.

Local and functional data use

CleanPrint handles article content and source/resource URLs in a bounded temporary snapshot; optional user-enabled requests to original image hosts. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
