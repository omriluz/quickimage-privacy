SlidesTimer: Floating Presentation Timer Privacy Policy

Effective date: 2026-09-29

Summary

SlidesTimer runs locally in Chrome. It does not collect, sell, share, or transmit personal information, browsing history, presentation content, or usage analytics. It has no developer server and makes no network requests.

Data handled

After the user clicks the toolbar icon, SlidesTimer temporarily accesses the active tab to add the timer interface. It scans rendered DOM text in memory for supported timer tags. If a tag is found, only that text node is updated in the page. Page text, URLs, titles, and timer activity are not saved or transmitted.

The only persisted value is the user's sound enabled/disabled preference in chrome.storage.local. Chrome stores it in the local browser profile. The extension does not use cloud sync.

Permissions

  • activeTab: gives temporary access to the current tab after an explicit toolbar click.
  • scripting: injects the packaged timer engine and interface into that tab.
  • storage: stores the sound preference.

SlidesTimer requests no persistent site access and no Google account access.

Audio

If the user enables sound, SlidesTimer uses the browser's Web Audio API to synthesize a short local chime. No audio is recorded or uploaded.

Retention and deletion

Timer state and inspected tag text remain only in the current tab's memory and disappear when the page is closed or navigates to another origin. To delete the sound preference, remove the extension or clear its extension storage.

Children and sensitive data

SlidesTimer does not knowingly collect any data, including data from children. Users should avoid placing unsupported timer tags in editable fields; the extension deliberately excludes inputs, textareas, and contenteditable regions from tag enhancement.

These publication fields must be completed before Chrome Web Store submission.

Local and functional data use

SlidesTimer handles temporary page DOM used for the timer overlay and a local sound preference. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
