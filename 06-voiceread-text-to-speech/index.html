VoiceRead: Text to Speech Privacy Policy

Last updated: 2026-09-29

VoiceRead has no analytics, advertising, account system, or developer-operated server. It does not sell user data and does not keep a reading history.

Data used for the core feature

When the user opens VoiceRead or invokes its selection context menu, the extension reads the selected text or visible main text of that active page. The text is bounded to 40,000 characters and held in extension memory for the current speech session. It is passed to Chrome's text-to-speech API in chunks and is not written to extension storage.

Chrome can expose voices supplied by the operating system or another installed speech engine. Chrome marks some voices as remote. If the user chooses a remote voice, Chrome or that voice provider may transmit the spoken text to the provider to create audio. VoiceRead labels those voices “may use network.” For voices where Chrome does not report remote status, VoiceRead labels the provider status as unknown. Provider processing is governed by the browser, operating system, speech-engine extension, or provider selected by the user.

Data stored locally

VoiceRead stores only these preferences in chrome.storage.local:

  • speech rate;
  • selected voice name and language;
  • selected speech-engine extension identifier, when Chrome supplies one.

These preferences stay in the Chrome profile unless the user or browser removes them. VoiceRead does not store page text, selections, audio, URLs, browsing history, or playback history.

Permissions

  • activeTab: temporary access to the current page after the user invokes VoiceRead.
  • scripting: injects the local extractor and highlighter into that user-invoked page.
  • tts: asks Chrome for installed voices and controls speech playback.
  • storage: saves the voice and speed preferences listed above.
  • contextMenus: adds the user-invoked “Read selection aloud with VoiceRead” command.

VoiceRead declares no host permissions.

Local and functional data use

VoiceRead handles page text in speech-session memory and local voice/rate preferences; chosen voice providers may process spoken text as described below. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
