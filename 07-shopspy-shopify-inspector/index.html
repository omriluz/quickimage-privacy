ShopSpy - Shopify Store Inspector Privacy Policy

What ShopSpy processes

ShopSpy runs only after the user clicks its toolbar action. On the active HTTP(S) page it reads:

  • the current origin and hostname;
  • public script, stylesheet, and iframe URLs;
  • a small set of public DOM markers;
  • public generator and currency meta tags;
  • readable inline Shopify.theme metadata;
  • public product fields returned by the active origin's /products.json endpoint, up to 250 products per popup session.

The catalog request is sent directly from the storefront page to the same storefront origin with credentials omitted. It does not include the user's storefront cookies through the extension request code.

Storage and transfer

Inspection results stay in the popup's memory and disappear when the popup closes. ShopSpy does not use Chrome storage, a remote server, analytics, advertising, telemetry, or account login. CSV files are created locally from the currently loaded store's products and downloaded only when the user clicks export.

ShopSpy does not request or read Shopify Admin, merchant account, customer, order, payment, private app, or private analytics data. It does not sell or share inspection data.

The inspected storefront still receives the public catalog requests, as it would receive other page requests. Chrome and the user's network environment may apply their own logging or privacy behavior.

Permissions

  • activeTab: temporary access to the tab the user explicitly invokes ShopSpy on.
  • scripting: injects the bundled local inspection code into that active tab.

No persistent host permission is requested.

These operational fields must be completed before publication. Catalog requests omit cookies and referrers, refuse redirects, time out after 10 seconds including response reading, and reject responses larger than 2 MB or more than 50 products per page. An inspection holds at most 250 products. Missing or malformed prices remain unknown.

Local and functional data use

ShopSpy handles storefront page/catalog content and current origin/resource URLs; popup results in memory. Local-only processing is still disclosed as data handling. Existing site and service privacy terms apply to the functional requests or user-directed transfers described above.

Limited Use

Use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the extension's disclosed single purpose and its associated local controls and status. The publisher does not sell user data, use or transfer it for unrelated purposes or advertising, or use it to determine creditworthiness or for lending. External recipients, when any, are limited to the functional, user-directed workflows described in this policy. The publisher does not operate a service that receives these extension records.
